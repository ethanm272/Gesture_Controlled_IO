# Gesture Controlled IO
This python app uses mediapipe, opencv, and pyautogui to recognize hand movements through your webcam to allow users to control their mouse

## Authors
Ethan Mylett

## Run Instructions
- Navigate to the directory containing this project
- Make sure the following dependencies are installed:
-- OpenCV
-- Mediapipe
-- Pyautogui
- Enter the command 'python3 mediapipe.py'
- Allow the program access to webcam and computer controls (may require re-run)

## Controls
The following controls are currently supported:
- index finger pointing up 👆 : begins finger tracking to move mouse
